# Використання проєкту Hello World

## Вимоги

- Node.js 24
- npm 10 або новіший

Перевірити встановлені версії можна командами:

```sh
node --version
npm --version
```

## Встановлення залежностей

У корені проєкту виконай:

```sh
npm ci
```

`npm ci` встановлює залежності відповідно до `package-lock.json`. Команда призначена для відтворюваного встановлення, зокрема в CI.

## Складання

```sh
npm run build
```

Команда запускає `tsc`, компілює файли `src/` у `build/`, а потім npm автоматично виконує `postbuild` для створення `build/hello` та `build/hello.cmd`.

## Тести

```sh
npm test
```

Команда запускає `vitest run`. Тести з `tests/index.test.ts` перевіряють `BasicAddition` для додатних чисел, від'ємного числа й нуля.

## Запуск програми

```sh
npm start
```

Команда запускає зібрану точку входу командою `node build/index.js`; застосунок виводить `Hello, World!`. Її можна запускати після успішного складання.

Також зібрану програму можна запускати платформним launcher-ом:

- Linux/macOS: `./build/hello`
- Windows PowerShell: `.\build\hello.cmd`
- Windows Command Prompt: `build\hello.cmd`

## Запуск CI локально

### Windows

Із кореня проєкту у PowerShell виконай:

```powershell
.\ci.bat
```

У Command Prompt:

```bat
ci.bat
```

`ci.bat` переходить у корінь репозиторію, перевіряє `package.json` та lock-файл, після чого запускає `npm ci`, `npm run build` і `npm test` у такій послідовності. При першій помилці скрипт зупиняється та повертає ненульовий код.

### Linux/macOS

Із кореня проєкту виконай:

```sh
bash ci.sh
```

`ci.sh` виконує ті самі перевірки й npm-команди, що й Windows-скрипт: перевіряє передумови, встановлює залежності, складає проєкт і запускає тести. Налаштування `set -euo pipefail` зупиняє скрипт при помилці або невизначеній змінній, а команда, що завершилася невдало, повертає ненульовий код.


## Автоматична перевірка на GitHub

GitHub Actions автоматично запускає CI під час `push` або `pull_request` до гілок `develop` і `master`.

Перевірка виконується на трьох платформах: Ubuntu, Windows і macOS. Для кожної платформи запускається відповідний CI-скрипт, який встановлює залежності, збирає проєкт і виконує тести.
